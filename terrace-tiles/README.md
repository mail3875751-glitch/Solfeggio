# Раскладка плитки — терраса пер. Инжирный

Параметрический расчёт вариантов раскладки плитки по контуру террасы.

## Запуск
```
pip install shapely ezdxf matplotlib openpyxl
python3 run_variants.py config/inzhirny_workplan.json out
```

## Что на выходе (папка `out/`)
- `<конфиг>_V*.png` — лист варианта (план, целые/резаные плитки, статистика)
- `<конфиг>_варианты.pdf` — все варианты одним файлом (A3)
- `<конфиг>_V*.dxf` — раскладка в DXF (мм), слои: KONTUR, ZONY, PLITKA_CEL, PLITKA_REZ, PLITKA_MELK, STYK, TEKST
- `<конфиг>_свод.xlsx`, `<конфиг>_свод.md` — сводная таблица расхода по вариантам и по зонам

## Конфиг
- `zones` — прямоугольники `[x0, y0, x1, y1]` или `polygon` (мм); ось X — вдоль террасы, Y — поперёк
- `junction_y` — линия стыка крытой и открытой части; на ней лежит шов, плитка идёт от стыка к краям
- `axis_x` — ось симметрии по длине (на ней шов или центр плитки — выбирается автоматически по меньшему числу подрезов)
- `joint` — ширина шва, мм
- `variants[]` — `pattern`: `grid` (прямая), `bond` + `offset` 0.5 / 0.3333 (вразбежку), `herringbone` (ёлочка); `angle` 0 / 45

## Как считается расход
- целая плитка — покрывает ≥ 99,9 % своей площади внутри контура; остальное — резаные куски
- «с учётом обрезков»: краевые полосы режутся из одной плитки (учёт реза 3 мм), угловые куски — по плитке на кусок;
  на диагонали/ёлочке треугольники ≤ ½ плитки паруются
- к расчётному расходу добавлять запас 5–7 % (прямая/вразбежку) или 10–15 % (диагональ/ёлочка) и округлять до коробок
